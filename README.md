# 🛠️ SillyCode - 個人實用工具箱

這是一個存放各類 Web 小工具、實驗性程式碼以及個人生活應用程式的倉庫。
這裡的專案多為單頁應用程式 (Single Page Applications)，涵蓋工程計算、金融試算與生活規劃等不同領域。

| 檔案名稱 | 功能描述 | 應用場景 |

## 💻 技術說明 (Tech Stack)

這些工具主要使用原生 Web 技術建構，輕量且無需安裝即可運行：
*   **HTML5**
*   **CSS3** (RWD 響應式設計)
*   **JavaScript** (ES6+)

## 📖 如何使用 (Usage)

1.  **線上使用**：直接點擊上方的 [GitHub Pages 連結](https://bingronglee.github.io/SillyCode/) 即可使用所有工具。
2.  **本地使用**：
    *   Clone 此倉庫：`git clone https://github.com/bingronglee/SillyCode.git`
    *   直接用瀏覽器打開對應的 `.html` 檔案即可。
